项目简介

StudyMate 是一个基于 HTML5、CSS3 和 JavaScript 开发的移动端学习管理助手。
该项目面向高校学生用户，旨在帮助学生更加高效地管理日常课程安排、学习任务以及学习时间。
系统通过移动端友好的界面设计，实现课程查看、任务管理以及番茄钟专注学习等功能，提高学生学习规划和时间管理效率。

一、项目背景
随着大学课程数量增加以及学习任务复杂化，学生经常面临以下问题：
- 课程信息分散，难以及时查看；
- 作业任务较多，容易遗漏截止日期；
- 学习时间缺少合理规划；
- 缺少简单有效的学习记录工具。
因此，本项目设计并开发一个轻量化的移动端学习管理系统，将课程管理、任务管理和专注学习功能进行整合，为学生提供便捷的一站式学习辅助工具。

二、用户需求分析
本系统主要面向大学生用户。
用户主要需求包括：
- 查看个人每周课程安排；
- 管理日常学习任务；
- 设置任务截止日期和优先级；
- 标记任务完成状态；
- 使用番茄钟提高学习效率；
- 保存学习数据，避免刷新页面后数据丢失。

三、功能需求分析
1. 首页模块（Index）
功能：
- 展示学习概览；
- 显示课程、任务以及专注学习情况；
- 提供快速进入各功能模块入口。
2. 课程管理模块（Course）
功能：
- 查看周一至周日课程安排；
- 显示课程名称、时间、地点等信息；
- 添加课程信息；
- 保存课程数据。
3. 学习任务管理模块（Task）
功能：
- 创建学习任务；
- 设置任务名称；
- 设置截止日期；
- 设置任务类别；
- 设置任务优先级；
支持：
- 添加任务；
- 删除任务；
- 完成任务；
- 任务筛选（全部 / 未完成 / 已完成）。
4. 专注学习模块（Focus）
功能：
- 提供番茄钟学习模式；
- 支持不同学习时间选择：25分钟、45分钟、60分钟
支持：
- 开始计时；暂停计时；继续计时；重置计时；
帮助用户培养专注学习习惯。
5. 个人中心模块（Profile）
功能：
- 展示个人信息；
- 查看学习相关数据。

四、技术方案
前端技术
本项目采用前端Web开发技术：
- HTML5
用于构建网页结构。
- CSS3
用于实现移动端页面布局、颜色以及样式设计。
- JavaScript
用于实现页面交互逻辑，包括：
- 数据处理；
- 任务管理；
- 倒计时功能；
- 页面动态更新。
数据存储
系统使用浏览器：LocalStorage
保存内容包括：
- 课程数据；
- 任务数据；
- 专注学习记录。
用户刷新页面后数据仍然存在。
